Berikut penjelasan teknologi yang kita gunakan saat ini dan bagaimana nanti ketika Anda deploy ke VPS:

1. Teknologi Backend yang Kita Pakai Sekarang
Backend backend-dashboard-dpw dibangun menggunakan standar industri Python modern:

Bahasa & Framework: Python 3.12 + Flask (REST API murni)
Database Driver & ORM: SQLAlchemy 2.0 + Psycopg2 (Driver resmi PostgreSQL)
Keamanan & Autentikasi: Flask-JWT-Extended (Token JWT stateless aman) + Bcrypt (Enkripsi password)
WSGI Production Server: Sudah disiapkan Waitress (untuk Windows) dan bisa memakai Gunicorn (untuk Linux VPS)
Koneksi Database Saat Ini: Masih diarahkan ke database PostgreSQL yang di-hosting di Supabase via connection pooler string standar:
env
DATABASE_URL=postgresql://postgres...:...@aws-0-ap-northeast-2.pooler.supabase.com:5432/postgres
NOTE

Kunci Penting: Backend ini TIDAK memakai SDK Supabase (Bukan vendor lock-in), melainkan memakai koneksi PostgreSQL murni. Artinya, backend ini tidak bergantung pada layanan Supabase sama sekali!

2. Bagaimana Nanti Saat Deploy ke VPS Sendiri?
Karena backend ini murni membaca koneksi dari environment variable DATABASE_URL, Anda tidak perlu mengubah kode program satu baris pun saat pindah ke VPS!

Langkah Anda nanti di VPS Ubuntu/Debian sangat sederhana:

Install PostgreSQL di VPS:
bash
sudo apt update
sudo apt install postgresql postgresql-contrib
Buat Database & User:
bash
sudo -u postgres psql
CREATE DATABASE dpw_sulut;
CREATE USER nasdem_user WITH ENCRYPTED PASSWORD 'PasswordKuat123';
GRANT ALL PRIVILEGES ON DATABASE dpw_sulut TO nasdem_user;
\q
Import Skema Tabel: File skema PostgreSQL lengkap sudah saya siapkan di 

database/schema.sql
 (sudah mencakup tabel members, urutan, audit_logs, deletion_requests, dan app_users):
bash
psql -U nasdem_user -d dpw_sulut -f database/schema.sql
Cukup Ganti 1 Baris di File .env: Di VPS, Anda tinggal ubah file 

.env
 menjadi:
env
DATABASE_URL=postgresql+psycopg2://nasdem_user:PasswordKuat123@localhost:5432/dpw_sulut
Jalankan Seed Admin:
bash
python -m scripts.seed_admin
Jalankan Backend dengan Gunicorn + Nginx/Systemd:
bash
gunicorn -w 4 -b 127.0.0.1:5000 wsgi:app
Keuntungan untuk Anda:
Sangat Hemat Biaya: Anda cukup menyewa 1 VPS murah (misalnya 2GB RAM / 1 vCPU seharga ~Rp 80.000 – 150.000/bulan di IDCloudHost, Biznet Gio, atau DigitalOcean) untuk menjalankan Frontend, Backend Flask, dan PostgreSQL sekaligus tanpa biaya bulanan cloud database.
Data 100% Milik Sendiri: Data kader dan KTP aman di server pribadi Anda, tanpa risiko pembatasan kuota (quota limits / row limits) dari pihak ketiga.
Backup Sangat Mudah: Cukup jalankan perintah pg_dump otomatis setiap hari ke file .sql.gz lokal atau Google Drive.
